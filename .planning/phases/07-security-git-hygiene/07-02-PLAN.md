    Create `.github/workflows/gitleaks.yml` as the repo's first workflow (Phase 9 adds lint/test separately per CONTEXT).

    Required structure per D-09/D-11/D-12:
    - `name: gitleaks`
    - Triggers: `on: push:` and `on: pull_request:` (no branch filter — all branches)
    - Single job `scan` on `ubuntu-latest`
    - Step 1: `actions/checkout@v6` with `fetch-depth: 0` (mandatory — shallow default misses history)
    - Step 2: `gitleaks/gitleaks-action@v3` with env `GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}`
    - Do NOT add pre-commit hook (D-12)
    - Do NOT set `fetch-depth: 1` or omit fetch-depth
    - Do NOT pin `gitleaks-action@v2` (deprecated)
    - Optional: set `GITLEAKS_VERSION: "8.30.1"` env on gitleaks step if local/CI drift is a concern (RESEARCH A3)

    Validate YAML parses: use `python3 -c "import yaml; yaml.safe_load(open('.github/workflows/gitleaks.yml'))"` or install `actionlint` if available.
