    1. Parse with `CatalogSeedParser.loadFromAssets`
    2. Load stored catalog via `findCatalogByCode(seed.code)`
    3. If `CatalogVersion.shouldMerge(seed.catalogVersion, stored?.catalogVersion)` is false, skip catalog
    4. Else run transactional merge (D-13):

    `mergeCatalog(seed)` recursively:
    - Upsert catalog entity with `id = stored?.id ?: 0`, resolve `catalogId`
    - For each category: lookup by `(catalogId, code)`, upsert with preserved `id`, resolve `categoryId`
    - For each badge: lookup by `(categoryId, code)`, upsert preserving `id`, set `imageAssetPath` from seed (nullable per D-04)
    - For each requirement: lookup by `(badgeId, code)`, upsert preserving `id` — progress FKs survive text updates (D-15)

    Wrap full catalog merge in `@Transaction` on a new `CatalogDao.mergeCatalogTransaction` method OR use `withTransaction` from Room database — pick one pattern and apply consistently.

    Do not delete removed requirements in v1 merge unless seed omits them intentionally — optional prune documented in code comment only if implemented.

    Wire `AppContainer` `init` block:

    ```kotlin
    CoroutineScope(SupervisorJob() + Dispatchers.IO).launch {
        CatalogSeedLoader(context.applicationContext, database.catalogDao()).seedIfNeeded()
    }
    ```
    Import `kotlinx.coroutines`. Do not block main thread.

    Loader talks to `CatalogDao` directly — not `CatalogRepository` (per PATTERNS.md).

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-2-13 | Tampering | Seed JSON parse | mitigate | Strict DTO parsing for production assets; `ignoreUnknownKeys = false` in production parser path |
| T-2-14 | Denial of Service | Large seed files | mitigate | Fail fast on parse errors; seed files under 2MB per catalog |
| T-2-15 | Tampering | Merge duplicates | mitigate | Lookup-by-code before upsert; `secondSeedRunDoesNotDuplicate` test |
| T-2-16 | Repudiation | Progress loss on update | mitigate | ID-preserving merge (D-15); `CatalogSeedMergeTest` |
| T-2-17 | Elevation | Main-thread seed | mitigate | `Dispatchers.IO` only; no `runBlocking` in Application |
| T-2-SC | Tampering | Dependency installs | accept | No new Gradle dependencies in this plan |
</threat_model>
