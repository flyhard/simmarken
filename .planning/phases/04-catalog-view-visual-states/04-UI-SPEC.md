## Spacing Scale

Declared values (multiples of 4, unit **dp**):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4dp | Overlay icon inset inside badge circle, tab text padding |
| sm | 8dp | Grid outer horizontal padding, category header bottom padding |
| md | 16dp | Screen horizontal padding, tab row vertical padding, detail screen padding |
| gap-md | 12dp | Badge grid cell horizontal and vertical gap (canonical cell-gap token per D-15) |
| lg | 24dp | Detail pin-to-name gap, empty-state vertical padding |
| xl | 32dp | Detail screen top content offset below app bar |
| 2xl | 48dp | Minimum touch target (back button, tab hit area) |
| 3xl | 64dp | — (unused this phase) |

**Exceptions:**
- Badge grid cell gap: **12dp** (`gap-md` token) horizontal and vertical — thumb-friendly per D-15
- Badge grid outer padding: **8dp** horizontal (sm), **4dp** top below tab row
- Category sticky header padding: **16dp** horizontal, **8dp** vertical
- Badge pin image inset inside square cell: **4dp** (xs) from cell edges
- Progress ring stroke width: **3dp** — visible at swim-hall glance (discretion default)
- State overlay circle diameter: **20dp** — bottom-right corner badge
- State overlay offset from pin corner: **2dp** inset from bottom-right
- Tab row height: **48dp** minimum touch target
- Detail large pin size: **160dp** square
- Grid pin image size: fills square cell minus 4dp inset (cell width computed from 3 columns)

**Source:** CONTEXT D-13–D-16, D-21–D-24; Phase 3 spacing carry-forward

### Visual hierarchy / focal point

**Primary focal point:** The badge pin grid — state-colored pins (grayscale → ring → cart/check overlays) are the swim-hall glance anchor. Category headers and tab row provide wayfinding; badge names are secondary labels below pins.

**Source:** Checker Dimension 2 recommendation; PROJECT.md core value

## Typography

Use `MaterialTheme.typography` roles — do not introduce custom font families in this phase.

| Role | Size | Weight | Line Height | Compose Role | Usage |
|------|------|--------|-------------|--------------|-------|
| Body | 16sp | 400 (Regular) | 1.5 (24sp) | `bodyLarge` | Detail stub text, empty catalog body |
| Label | 14sp | 500 (Medium) | 1.43 (20sp) | `labelLarge` | Badge name under grid pin, tab labels |
| Heading | 22sp | 400 (Regular) | 1.27 (28sp) | `titleLarge` | Top app bar (child name), detail badge name |
| Display | 16sp | 500 (Medium) | 1.25 (20sp) | `titleMedium` | Sticky category headers |

**Badge name in grid:** `labelLarge` (14sp Medium), `maxLines = 1`, `TextOverflow.Ellipsis`, centered below pin, `4dp` top gap from pin.

**Category header:** `titleMedium` (16sp Medium), `color = onSurface`, single line, no truncation expected for official tier names.

**Weights used:** Regular (400) + Medium (500) only.

**Source:** Material 3 default type scale; CONTEXT D-14, D-17–D-19

## Color

### Surface split (60 / 30 / 10)

| Role | Token | Light | Dark | Usage |
|------|-------|-------|------|-------|
| Dominant (60%) | `colorScheme.background` | `#FFFBFE` | `#1C1B1F` | Scaffold background, catalog scroll area |
| Secondary (30%) | `colorScheme.surfaceContainerLow` | `#F7F2FA` | `#1D1B20` | Sticky category header background, tab row surface |
| Accent (10%) | `colorScheme.primary` | `#2196F3` | `#2196F3` | Selected tab indicator, progress ring stroke, focused states |
| Destructive | `colorScheme.error` | M3 default | M3 default | Not used this phase (no destructive actions) |

### Badge visual state colors

| State | Pin image | Progress ring | Overlay |
|-------|-----------|---------------|---------|
| `LOCKED` | Grayscale (`saturation = 0`) | None | None |
| `IN_PROGRESS` | Grayscale (`saturation = 0`) | `primary` arc, proportional fill | None |
| `ACHIEVED_TO_BUY` | Full color | None | `primary` filled circle + white cart icon |
| `GOTTEN` | Full color | None | `primary` filled circle + white checkmark icon |

**Grayscale implementation:** `ColorFilter.colorMatrix(SaturationMatrix(0f))` on Coil `AsyncImage` for `LOCKED` and `IN_PROGRESS`. Full color (no filter) for `ACHIEVED_TO_BUY` and `GOTTEN`.

**Progress ring track:** `primary.copy(alpha = 0.2f)` full circle behind arc.

**Progress ring arc:** `primary` at 100% opacity; `StrokeCap.Round`; sweep angle = `(achievedCount / totalCount) * 360f`; start angle `-90f` (12 o'clock). Hidden when `totalCount == 0` or state is not `IN_PROGRESS`.

**State overlay circle:** `MaterialTheme.colorScheme.primary` fill, `CircleShape`, `20dp` diameter, `2dp` offset from bottom-right of pin bounds.

**State overlay icon:** `Color.White`, `12dp` size, centered in circle. Cart: `Icons.Filled.ShoppingCart`. Checkmark: `Icons.Filled.Check`.

**Tier-color fallback** (when `imageAssetPath` is null): Use existing `BadgePlaceholderColors` tier mapping — colored `Box` with `CircleShape` or rounded rect, badge initials or short code in white `labelLarge`. Same grayscale filter rules apply to placeholder fills for locked/in-progress.

**Accent reserved for:**
- Selected catalog tab indicator and label emphasis
- Progress ring stroke and track tint
- Cart/checkmark overlay circle fill
- **Not** used for category header text, badge names, pin art backgrounds, or grid cell backgrounds

**Source:** CONTEXT D-09–D-12, D-21–D-24, D-29–D-30; `Color.kt`

## Interaction Specifications

### Navigation flow

```
HomeScreen
  └─ ChildCard tap → ChildCatalogScreen(kidId)
       ├─ Tab Simidrott / SLS (session switch)
       ├─ Scroll categories (sticky headers)
       └─ BadgeGridItem tap → BadgeDetailPlaceholderScreen(kidId, badgeId)
            └─ Back → ChildCatalogScreen (tab resets to Simidrott on re-entry only)
```

### Touch targets

| Element | Min size | Notes |
|---------|----------|-------|
| Back `IconButton` | 48×48dp | Top app bar |
| Tab | 48dp height × half screen width | PrimaryTabRow |
| Badge grid cell | Full cell (pin + name) | Navigate to detail |
| Category header | Non-interactive | Scroll only |

### Gestures

| Gesture | Target | Result |
|---------|--------|--------|
| Tap | Tab | Switch catalog |
| Tap | Badge cell | Push `BadgeDetail` route |
| Tap | Back | Pop stack |
| Vertical scroll | Catalog list | Scroll badges; headers stick |
| Long press | — | No action this phase |

### State derivation inputs (read-only)

- `ProgressRepository.observeRequirementProgress(kidId)`
- `ProgressRepository.observeBadgeProgress(kidId)` → `isGotten`
- `CatalogRepository.observeCategories(catalogId)`, `observeBadges(categoryId)`

No writes from Phase 4 UI.

## Badge Visual State Matrix

| State | Pin color | Ring | Overlay | Name text |
|-------|-----------|------|---------|-----------|
| LOCKED | Grayscale | — | — | `onSurface` |
| IN_PROGRESS | Grayscale | Partial primary arc | — | `onSurface` |
| ACHIEVED_TO_BUY | Full color | — | Cart circle | `onSurface` |
| GOTTEN | Full color | — | Check circle | `onSurface` |

**Transition rules (display logic, Phase 5 will trigger writes):**
- First requirement checked → LOCKED → IN_PROGRESS immediately (D-07)
- All requirements met → IN_PROGRESS → ACHIEVED_TO_BUY, ring removed (D-12)
- `isGotten` true → GOTTEN regardless of requirements (D-30 precedence)

| Category | Element(s) | Status | Resolution / Reason |

| overflow | `ChildCatalogScreen`, `CatalogTabRow`, `BadgeGrid`, `CatalogEmptyState`, `BadgeDetailPlaceholderScreen`, `CategoryStickyHeader` | ✅ covered | Catalog body scrolls vertically (`LazyColumn`); badge names `maxLines=1` + ellipsis; top app bar titles ellipsis; empty-state body wraps within padded center column |

| long-text | `CatalogTabRow`, `CatalogEmptyState`, `BadgeDetailPlaceholderScreen`, `CategoryStickyHeader`, `BadgeGridItem` | ✅ covered | Tab labels fixed short (`Simidrott`/`SLS`); category headers single-line official tier names; child/badge names in app bar and grid use ellipsis; detail stub text wraps if needed |
