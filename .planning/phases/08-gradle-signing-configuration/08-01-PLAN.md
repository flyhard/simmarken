<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Gradle config → filesystem | Untrusted/missing keystore.properties and env vars cross into signing resolver |
| CI runner env → Gradle decode | ANDROID_KEYSTORE_BASE64 and passwords injected at build time (D-12) |
| Release task graph → artifact | Unsigned or wrong-key AAB must not ship silently |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01 | Tampering | bundleRelease without signingConfig | high | mitigate | whenReady GradleException before task execution (D-01); signingConfig = findByName("release") only |
| T-08-02 | Information Disclosure | Passwords in build.gradle.kts | high | mitigate | Credentials only from gitignored keystore.properties or env vars; never hardcode |
| T-08-03 | Tampering | Debug keystore on release | medium | mitigate | Nullable release signingConfig; no debug fallback assignment |
| T-08-04 | Denial of Service | Config-time crash on missing props | medium | mitigate | Resolver returns null when incomplete; guard only on release tasks (D-02) |
| T-08-05 | Information Disclosure | Base64 keystore in logs | medium | mitigate | Do not println env vars; write decoded file under app/build/signing/ only |
| T-08-SC | Tampering | Malicious Gradle/plugin changes | high | mitigate | No new package installs; review diff in app/build.gradle.kts only |

</threat_model>
