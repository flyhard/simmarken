## Spacing Scale

Declared values (multiples of 4, unit **dp**):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4dp | Icon-to-label gap, swatch grid gap |
| sm | 8dp | Card internal padding between avatar and name |
| md | 16dp | Screen horizontal padding, list item vertical gap, form field spacing |
| lg | 24dp | Empty-state vertical padding, bottom sheet content padding |
| xl | 32dp | Empty-state icon/text gap |
| 2xl | 48dp | Minimum touch target size (FAB, icon buttons, swatches) |
| 3xl | 64dp | Avatar circle diameter |

**Exceptions:**
- Child card minimum height: **72dp** (avatar 48dp + 12dp vertical padding × 2) — exceeds touch target without extra padding
- FAB size: **56dp** (Material 3 standard Large FAB)
- Bottom sheet drag handle area: **32dp** top inset (system default)

**Source:** Material 3 guidelines + CONTEXT D-01 (full-width thumb-reachable cards)

## Typography

Use `MaterialTheme.typography` roles — do not introduce custom font families in this phase.

| Role | Size | Weight | Line Height | Compose Role | Usage |
|------|------|--------|-------------|--------------|-------|
| Body | 16sp | 400 (Regular) | 1.5 (24sp) | `bodyLarge` | Card child name, form labels, dialog body |
| Label | 14sp | 500 (Medium) | 1.43 (20sp) | `labelLarge` | FAB extended label (if used), validation error, button labels |
| Heading | 22sp | 400 (Regular) | 1.27 (28sp) | `titleLarge` | Top app bar title, bottom sheet title, empty state heading |
| Display | 28sp | 400 (Regular) | 1.2 (34sp) | `headlineSmall` | Avatar initials inside 48dp circle (scale down to 20sp if name yields 3+ chars) |

**Weights used:** Regular (400) + Medium (500) only. Semibold not introduced this phase.

**Source:** Material 3 default type scale; discretion default

## Color

### Surface split (60 / 30 / 10)

| Role | Token | Light | Dark | Usage |
|------|-------|-------|------|-------|
| Dominant (60%) | `colorScheme.background` | `#FFFBFE` | `#1C1B1F` | Scaffold background, screen base |
| Secondary (30%) | `colorScheme.surfaceContainerLow` | `#F7F2FA` | `#1D1B20` | Child cards (`ElevatedCard`), bottom sheet surface |
| Accent (10%) | `colorScheme.primary` | `#2196F3` | `#2196F3` | FAB, save button, selected swatch ring, focused text field indicator |
| Destructive | `colorScheme.error` | M3 default | M3 default | Delete confirmation confirm button, delete menu item text |

### Avatar swatch palette

New object: `KidAvatarColors` in `ui/theme/` (or `ui/home/`). **10 preset ARGB values** — distinct, accessible on white initials text:

| Index | ARGB | Hex | Name (internal) |
|-------|------|-----|-----------------|
| 0 | `0xFFE53935` | `#E53935` | Red |
| 1 | `0xFFFB8C00` | `#FB8C00` | Orange |
| 2 | `0xFFFDD835` | `#FDD835` | Yellow |
| 3 | `0xFF43A047` | `#43A047` | Green |
| 4 | `0xFF1E88E5` | `#1E88E5` | Blue |
| 5 | `0xFF8E24AA` | `#8E24AA` | Purple |
| 6 | `0xFFD81B60` | `#D81B60` | Pink |
| 7 | `0xFF00ACC1` | `#00ACC1` | Cyan |
| 8 | `0xFF6D4C41` | `#6D4C41` | Brown |
| 9 | `0xFF546E7A` | `#546E7A` | Blue Grey |

**Default color algorithm:** `KidAvatarColors.palette[abs(name.trim().hashCode()) % palette.size]` — applied on add when parent has not yet picked a swatch.

**Initials text color:** `Color.White` on all swatches (verify contrast; yellow uses `Color.Black` if contrast fails WCAG AA).

**Accent reserved for:**
- FAB background (`FloatingActionButton`)
- Primary action buttons (Spara / Lägg till)
- Selected color swatch outer ring (`2dp` border, `primary`)
- Text field cursor and focused underline
- **Not** used for card backgrounds, avatar fills, or overflow menu

**Source:** CONTEXT D-07, discretion; pattern follows `BadgePlaceholderColors.kt`

## Interaction Specifications

### Navigation flow

```
HomeScreen
  ├─ FAB / Empty state hint → KidFormBottomSheet (add)
  ├─ ChildCard tap → ChildCatalogPlaceholder(kidId)
  ├─ Overflow → Edit → KidFormBottomSheet (edit)
  └─ Overflow → Delete → DeleteKidDialog → confirm → remove from Room
```

### Touch targets

| Element | Min size | Notes |
|---------|----------|-------|
| Child card (tap area) | Full width × 72dp min | Primary navigation target |
| Overflow `IconButton` | 48×48dp | Isolated from card navigation |
| FAB | 56×56dp | M3 large FAB |
| Color swatch | 48×48dp | Includes transparent hit padding if visual is 40dp |
| Dropdown menu items | 48dp height | `DropdownMenuItem` default |
| Dialog buttons | 48dp height | `TextButton` minimum |
| Bottom sheet drag handle | 48dp wide touch zone | System default |

### Gestures

| Gesture | Target | Result |
|---------|--------|--------|
| Tap | Card body | Navigate to catalog |
| Tap | Overflow | Open menu |
| Tap | FAB | Open add form sheet |
| Tap | Swatch | Select avatar color |
| Swipe down | Bottom sheet | Dismiss without save |
| Back | Any screen / dialog | Pop or dismiss per stack |

### List ordering

Display children ordered by `sortOrder ASC`, then `createdAtEpochMillis ASC` (D-04). New kid gets `sortOrder = currentMax + 1` or `createdAtEpochMillis` as tiebreaker.

## Motion & Elevation

Material 3 tonal elevation — no custom shadow values.

| Surface | Elevation token | dp (approx) | Usage |
|---------|-----------------|-------------|-------|
| Screen background | 0 | 0 | Scaffold |
| Child card | `Level1` | 1 | `ElevatedCard` default |
| FAB | `Level3` | 3 | Floating action |
| Bottom sheet | `Level2` | 2 | Modal sheet surface |
| Dialog | `Level3` | 3 | Alert dialog |

### Motion tokens

| Transition | Spec |
|------------|------|
| Bottom sheet enter/exit | `BottomSheetDefaults` — slide + fade, ~300ms |
| Dialog enter/exit | `AlertDialog` default — scale + fade |
| List item appear | None (static list; no stagger animation) |
| Navigation | `NavHost` default crossfade / slide |
| FAB | No morph — standard show/hide |

**Source:** Material 3 motion defaults; discretion
