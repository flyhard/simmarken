# Phase 5 — UI Design Contract

**Requirements:** UI-03, PROG-01, PROG-02, PROG-03, PROG-05  
**Primary locale:** Swedish (hardcoded until Phase 6 i18n)  
**Scope:** Interactive badge detail (checklist + purchase toggle), home child-card summary counts. Replaces `BadgeDetailPlaceholderScreen`. No export/import or full i18n (Phase 6).

### Visual hierarchy / focal point

**Primary focal point:** Requirement checklist rows — large tap targets with instant checkbox feedback are the swim-hall interaction anchor. Pin visual at top confirms which badge is being edited; purchase toggle is secondary, gated until skills complete.

**Secondary focal point (home):** Child name remains primary on `ChildCard`; progress summary subtitles (`pågår` / `att köpa`) are tertiary `bodySmall` lines that surface attention items without competing with the name.

**Source:** PROJECT.md core value; CONTEXT D-01, D-13

## Typography

Carry forward Phase 4 roles. **No new font families.**

| Role | Size | Weight | Line Height | Compose Role | Usage |
|------|------|--------|-------------|--------------|-------|
| Body | 16sp | 400 (Regular) | 1.5 (24sp) | `bodyLarge` | Requirement text, zero-requirement note, purchase label |
| Label | 14sp | 500 (Medium) | 1.43 (20sp) | `labelLarge` | — (grid only, Phase 4) |
| Heading | 22sp | 400 (Regular) | 1.27 (28sp) | `titleLarge` | Top app bar badge name, detail badge name below pin |
| Display | 16sp | 500 (Medium) | 1.25 (20sp) | `titleMedium` | — (category headers, Phase 4) |
| Caption | 12sp | 400 (Regular) | 1.33 (16sp) | `bodySmall` | Progress subtitle `"X av Y klara"`, home card summary lines |

**Progress subtitle (`"X av Y klara"`):** `bodySmall`, `color = onSurfaceVariant`, centered below badge name (D-03). Hidden when `totalRequirements == 0` (zero-requirement badges use note instead).

**Requirement text:** `bodyLarge`, `color = onSurface`, `maxLines = Int.MAX_VALUE` (wrap freely — official requirement strings can be long).

**Purchase label (`"Fysiskt märke köpt"`):** `bodyLarge`, `color = onSurface` when enabled; `onSurface.copy(alpha = 0.38f)` when switch disabled (D-06 discretion default — greyed label, switch visible but inactive).

**Home summary subtitles:** `bodySmall`, `color = onSurfaceVariant`, left-aligned below child name, `maxLines = 1`.

**Weights used:** Regular (400) + Medium (500) only.

**Source:** Phase 4 Typography; CONTEXT D-02, D-03, D-05, D-13

## Copywriting Contract

All strings hardcoded Swedish this phase. Phase 6 migrates to `strings.xml`.

| Element | Copy |
|---------|------|
| Top app bar title | `{badgeName}` (`nameSv`) |
| Back button content description | `Tillbaka` |
| Progress subtitle | `{achievedCount} av {totalRequirements} klara` — e.g. `2 av 5 klara` |
| Zero-requirement note | `Inga kunskapskrav` (default); if seed provides descriptive `textSv` on a sentinel requirement, prefer that string |
| Purchase toggle label | `Fysiskt märke köpt` |
| Purchase toggle content description (on) | `Fysiskt märke köpt` |
| Purchase toggle content description (off) | `Fysiskt märke inte köpt` |
| Purchase toggle disabled hint (optional `contentDescription` append) | `Klar att köpa när alla krav är uppfyllda` — only when disabled due to incomplete skills |
| Köpt undo dialog title | `Ta bort köpt-markering?` |
| Köpt undo dialog body | `Märket visas inte längre som köpt. Kraven du bockat av behålls.` |
| Köpt undo confirm button | `Ta bort markering` |
| Köpt undo dismiss button | `Avbryt` |
| Home summary — in progress | `{count} pågår` — e.g. `2 pågår` |
| Home summary — to buy | `{count} att köpa` — e.g. `1 att köpa` |
| Badge missing (detail) | `Märket hittades inte` |
| Requirement row content description | `{requirementText}, {checked ? "klar" : "ej klar"}` |

**Primary CTA:** None — requirement rows and purchase switch are inline toggles; no separate submit/save button (instant persist per D-12, D-19).

**Empty state:** Zero-requirement badge shows `Inga kunskapskrav` note instead of empty checklist (D-04). Home card hides summary lines when counts are zero (D-14) — no "0 pågår" copy.

**Error state:** Badge not found → `Märket hittades inte` centered (existing placeholder pattern). Room write failures: no user-facing error UI in v1 — offline local DB; log and rely on Flow re-emission on retry (PITFALLS dismiss).

**Destructive confirmation:** Köpt undo only (D-07) — `Ta bort köpt-markering?` dialog. Unchecking skills while GOTTEN auto-clears köpt **without** dialog (D-10). Unchecking individual skills has no confirmation (D-12).

**Source:** CONTEXT D-03–D-07, D-10, D-12–D-14; `DeleteKidDialog` pattern

## Interaction Specifications

### Navigation flow

```
HomeScreen
  └─ ChildCard (with summary subtitles) tap → ChildCatalogScreen
       └─ BadgeGridItem tap → BadgeDetailScreen(kidId, badgeId)
            ├─ Toggle requirement rows → instant persist → pin/overlay updates
            ├─ Purchase switch on → instant persist → GOTTEN overlay
            ├─ Purchase switch off → UncheckPurchaseDialog → confirm/cancel
            └─ Back → ChildCatalogScreen (grid reflects new state via shared Flows)
```

### Touch targets

| Element | Min size | Notes |
|---------|----------|-------|
| Back `IconButton` | 48×48dp | Top app bar |
| Requirement row | 48dp height × full width | Row + checkbox (D-02) |
| Checkbox | 48dp touch area | M3 default minimum |
| Purchase switch row | 48dp height | Label + switch |
| ChildCard tap area | Full card minus overflow | Name + subtitles included |
| Overflow menu | 48×48dp | Unchanged |

### Gestures

| Gesture | Target | Result |
|---------|--------|--------|
| Tap | Requirement row / checkbox | Toggle achieved, persist |
| Tap | Purchase switch (enabled) | Toggle köpt or show undo dialog |
| Tap | Back | Pop stack |
| Tap | ChildCard body | Navigate to catalog |
| Vertical scroll | Detail checklist body | Scroll requirements; pin stays fixed |
| Long press | — | No action |

### State transition side effects (UI-visible)

| User action | Visual result | Persist |
|-------------|---------------|---------|
| Check first requirement | LOCKED → IN_PROGRESS; ring appears | `RequirementProgressEntity` |
| Check last requirement | IN_PROGRESS → ACHIEVED_TO_BUY; ring → cart overlay; switch enables | + `achievedAtEpochMillis` write-once (D-18) |
| Uncheck while ACHIEVED_TO_BUY | → IN_PROGRESS; cart → ring | Requirement only; `achievedAt` retained (D-09) |
| Uncheck to zero (with requirements) | → LOCKED; grayscale, no ring (D-11) | Requirement only |
| Toggle köpt on | → GOTTEN; check overlay | `isGotten`, `gottenAtEpochMillis` |
| Toggle köpt off (confirmed) | → ACHIEVED_TO_BUY; cart overlay | Clear gotten fields |
| Uncheck skill while GOTTEN | → IN_PROGRESS or LOCKED; auto-clear gotten (D-10) | Clear gotten + requirement |

### State derivation inputs

- `ProgressRepository.observeRequirementProgress(kidId)`
- `ProgressRepository.observeBadgeProgress(kidId)`
- `CatalogRepository.observeRequirements(badgeId)`
- `BadgeStateCalculator.compute` / `progressFraction` — **single path** for detail, grid, and home counts (Pitfall 3)
