# Phase 6 — UI Design Contract

> Visual and interaction contract for Export/Import & i18n. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Requirements:** DATA-02, DATA-03, I18N-01, I18N-02, I18N-03  
**Primary locale:** Swedish (`values/strings.xml` default); English (`values-en/strings.xml`)  
**Scope:** Settings screen (language + data backup), export share sheet with optional kid picker, import preview/confirm with per-new-kid selection, full chrome i18n migration. Catalog badge/requirement text remains Swedish (`nameSv`/`textSv`) in all locales.

| Property | Value |
|----------|-------|
| Platform | Android — Jetpack Compose |

| shadcn | Not applicable — Android native |

## Spacing Scale

Declared values (multiples of 4, unit **dp**) — **unchanged from Phase 5** unless noted:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4dp | Radio-to-label gap, list item internal gaps |
| sm | 8dp | Home card list gap, settings row vertical padding |
| md | 16dp | Screen horizontal padding, section gaps, dialog horizontal inset |
| lg | 24dp | Section title to first row, dialog section breaks |
| xl | 32dp | Settings top content offset below app bar |
| 2xl | 48dp | Minimum touch target (gear, back, settings rows, dialog buttons) |
| 3xl | 64dp | — (unused this phase) |

**Phase 6 exceptions / additions:**

| Element | Value | Notes |
|---------|-------|-------|
| Settings screen horizontal padding | 16dp (md) | Same as Home |
| Settings section vertical gap | 24dp (lg) | Between Language block and Data block |
| Section title bottom padding | 8dp (sm) | Below `titleMedium` section header |
| Settings row min height | 48dp (2xl) | Export / Import action rows |
| Settings row horizontal padding | 16dp (md) | Leading/trailing within screen |
| Language radio row min height | 48dp (2xl) | Full-row tap target |
| Language radio leading inset | 16dp (md) | Align with section content |
| `HorizontalDivider` between sections | 1dp `outlineVariant`, 24dp vertical margin | Optional between Language and Data |
| Kid picker dialog list max height | 320dp with `verticalScroll` | Prevents overflow when many kids |
| Import summary dialog body max height | 400dp with `verticalScroll` | Long update lists scroll inside dialog |
| Home top bar actions gap | 0dp (M3 default) | Gear `IconButton` trailing in `actions` slot |
| Snackbar bottom margin | 16dp (md) above nav gesture | When shown over Settings or Home |
| Checkbox-to-label gap | 12dp | Kid picker, import new-kid checklist, language radio label — balances M3 checkbox width vs text (exception, not a scale token) |
| Language radio label gap | 12dp | Between `RadioButton` and label in `LanguageRadioRow` (same exception) |

**Source:** Phase 5 spacing carry-forward; CONTEXT D-09–D-11; RESEARCH discretion

### Visual hierarchy / focal point

**Primary focal point (Settings):** Language radio group and Data action rows — parents configure locale and backup at the pool edge; sections are scannable list blocks, not cards.

**Secondary focal point (dialogs):** Import confirm dialog — summary counts and new-kid checklist are the decision anchor before any merge write (D-03, D-02).

**Home gear:** Tertiary affordance in top app bar — visible but does not compete with child cards or FAB.

**Source:** CONTEXT D-03, D-09; PROJECT.md phone-migration story

## Interaction Specifications

### Navigation flow

```
HomeScreen
  ├─ Gear IconButton → SettingsScreen
  │     ├─ Language radio → immediate locale change (Activity recreate)
  │     ├─ Export row → [if 2+ kids: ExportKidPickerDialog] → system share sheet
  │     └─ Import row → document picker → ImportConfirmDialog → merge / snackbar
  ├─ FAB / ChildCard → (unchanged)
  └─ External: ACTION_VIEW / ACTION_SEND JSON → MainActivity → ImportConfirmDialog (same gate)
```

### Touch targets

| Element | Min size | Notes |
|---------|----------|-------|
| Settings gear `IconButton` | 48×48dp | Home top bar trailing |
| Back `IconButton` | 48×48dp | Settings top bar |
| Language radio row | 48dp height × full width | Row clickable |
| Export / Import rows | 48dp height × full width | Settings Data section |
| Kid picker checkbox row | 48dp height | Dialog |
| Import new-kid checkbox row | 48dp height | Dialog |
| Dialog buttons | 48dp height | M3 default |

### Gestures

| Gesture | Target | Result |
|---------|--------|--------|
| Tap | Settings gear | Navigate to Settings |
| Tap | Language row | Select locale, apply immediately |
| Tap | Export row | Start export flow |
| Tap | Import row | Open document picker |
| Tap | Share sheet target | OS-handled (out of app) |
| Back | Settings | Pop to Home |

### Export flow state machine

| Device kids | User action | UI |
|-------------|-------------|-----|
| 0 | Export row tap | Snackbar or inline: no kids to export (edge — empty home normally has no export need; disable row or show `Inga barn att exportera` — executor choice, prefer disabled row) |
| 1 | Export row tap | Generate JSON → share sheet immediately (D-06) |
| 2+ | Export row tap | `ExportKidPickerDialog` → confirm → share sheet (D-07) |

### Import flow state machine

| Step | UI | Write? |
|------|-----|--------|
| Pick file / receive intent | — | No |
| Parse + validate fail | `ImportErrorDialog` | No |
| Parse OK | `ImportConfirmDialog` with summary | No |
| User Cancel | Dismiss | No |
| User Import | Snackbar success | Yes (transactional merge) |
